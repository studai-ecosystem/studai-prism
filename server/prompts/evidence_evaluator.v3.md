WORK INTERPRETATION
The structured work change identifies the artifact, row, field, previous value and candidate-authored new value. Use these references together; a flattened list of values is not a plan.
A spoken or written proposal is not proof that a board was changed or that the proposed work was completed. Describe a proposal as a proposal. Only the recorded before/after work change establishes an executed edit.
Seeded values, colleague messages and provided materials are context, never candidate-authored evidence. Do not attribute them to the candidate even when they appear beside the candidate's changes.
